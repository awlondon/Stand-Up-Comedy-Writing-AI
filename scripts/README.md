# Scripts for Stand-Up Comedy Set

This directory contains scripts to generate, test, and schedule the final presentation of the stand-up comedy set.

## Scripts

- `presentation.js`: Assembles the final presentation document.
- `test.js`: Tests the correctness of the final presentation document.
- `schedule.js`: Generates a schedule for the presentation of the comedy set.
- `index.js`: Runs all the scripts in sequence.

To run the scripts, execute `node scripts/index.js`.
