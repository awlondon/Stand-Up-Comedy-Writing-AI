# Write a timeless, original, evocative stand-up comedy set inspired by the greatest comedy writers and...

**Purpose:** Write a timeless, original, evocative stand-up comedy set inspired by the greatest comedy writers and standups of the past 50 years, but make it unique to you.

This repository holds a deliverable produced by a PDC Zooid Colony. It is laid out so it can be pushed to GitHub as it is:

```
git init && git add . && git commit -m "Initial commit"
```

## Layout

- `docs/`
- `deliverables/`
- `notes/`
- `PROJECT.json` - the definition of done the colony works against (editable)
- `STATUS.md` - which requirements hold right now, and who is working on what

The finished product is `deliverables/final.md`; the Zooids write it.
